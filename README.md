# Walmart Sales Analysis

## Project Overview

This project focuses on analyzing Walmart sales data to understand sales performance, store-level performance, monthly sales trends, yearly sales patterns, and the impact of holidays on sales.

The project was completed using **Excel, SQL, and Tableau**, covering the complete workflow from data preparation and analysis to business intelligence and visualization.

## Business Objective

The main objective of this project is to analyze Walmart sales data and identify meaningful business insights that can help understand:

* Overall sales performance
* Store-wise sales performance
* Monthly and yearly sales trends
* Top-performing stores
* Holiday vs. non-holiday sales performance
* Sales patterns that can support business decision-making

## Tools Used

* **Microsoft Excel** – Data preparation, cleaning, and initial analysis
* **SQL** – Data querying, filtering, aggregation, grouping, and business analysis
* **Tableau** – Data visualization and interactive dashboard creation

## Analysis Performed

### Excel

Excel was used for initial data preparation and analysis, including:

* Data cleaning
* Sorting and filtering
* Data validation
* Calculations and aggregations
* Preparing data for further analysis

### SQL

SQL was used to perform business-oriented analysis on the Walmart sales data.

The analysis included:

* Filtering data using `WHERE`
* Sorting using `ORDER BY`
* Aggregations using `SUM`, `AVG`, `COUNT`, `MAX`, and `MIN`
* Grouping data using `GROUP BY`
* Filtering aggregated results using `HAVING`
* Analyzing store and sales performance

### Tableau

Tableau was used to create an interactive **Walmart Sales Analysis Dashboard**.

The dashboard includes:

* Total Sales
* Average Weekly Sales
* Number of Stores
* Monthly Sales Trend
* Store Performance
* Top 5 Stores by Sales
* Holiday vs. Non-Holiday Sales
* Top 5 Yearly Sales
* Year filter for interactive analysis

## Key Insights

The Tableau dashboard provides the following high-level findings:

* Total sales across the analyzed Walmart stores were approximately **$6.74B**.
* The dataset contains **45 stores**.
* Average weekly sales were approximately **$1.05M**.
* Store performance varies across locations, allowing identification of the top-performing stores.
* Monthly and yearly trends help identify changes in sales performance over time.
* Holiday and non-holiday sales can be compared to understand differences in sales behavior.
* The Top 5 store analysis highlights the stores contributing strongly to overall sales.
